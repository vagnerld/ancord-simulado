# Simulado ANCORD

Prova clicável com os 6 simulados de fevereiro de 2024 da Academia Rafael Toro.

Escolha o simulado, responda as 80 questões e veja o percentual. A aprovação é com 70% (56 acertos). No final, as questões erradas aparecem com a resposta correta.

## Desenvolvimento

```bash
npm install
npm run dev
```
